# 3DISHES - Khám phá ẩm thực các nước

Khám phá các combo nguyên liệu để mở khóa món ăn với Window XP UI style
Cẩn thận quảng cáo pop-up nếu bạn sai nhiều quá

## Run

```bash
npm run dev
```

## Main Dishes

| Main Dishes | Recipe | 
|-----|--------|
| Spaghetti | Mì, Thịt bò, Sốt cà chua, Tỏi, Phô mai |
| Burrito | Bột mì, Thịt bò, Sốt cà chua, Phô mai, Xà lách |
| Empadana | Bột mì, Thịt bò, Tỏi, Hành tây, Trứng |
| Pad Thai | Mì, Tôm, Trứng, Hành lá, Đậu phộng |
| Takoyaki | Bột mì, Bạch tuộc, Hành tây, Trứng, Hành lá |
